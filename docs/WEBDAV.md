# WebDAV 手动同步

在「数据隐私 → WebDAV 同步」中配置网盘。网页版和 Windows 本地版使用相同的 Folio JSON 备份格式，支持普通备份和现有的 AES-GCM 加密备份。

## 配置

1. 点击「配置」，只填写服务商提供的 **HTTPS WebDAV 地址**、用户名、密码或应用专用密码。不要填写网盘分享链接。
2. 点击「连接并保存」，会先检查连接。主页仅保留「配置 / 上传 / 拉取」三个入口。
3. 首次上传时自动在所填地址下创建 `Folio_Backup` 文件夹，保存为 `Folio_Backup/folio-wallet.json`。两端拉取都自动读取这个固定位置，无需填写目录或文件名。

地址、用户名和连接状态仅保存在当前浏览器或桌面 WebView 的本机设置中。WebDAV 密码只保留在当前应用会话内，刷新、重启、退出登录或锁定卡包后需要重新输入。密码不会写入备份、数据库或设置文件。

网页版通过已登录站点的 Worker 中转请求，因此网盘需有公网可访问的 HTTPS 域名。桌面版通过原生 HTTPS 客户端连接，不经过 Folio 网站，不受浏览器 CORS 限制。两端均使用 Basic 认证和有效 TLS 证书，不支持 HTTP、交互式 OAuth 或在服务地址中携带凭据。

支持 Cloudreve 等网盘的 HTTPS 下载重定向，下载地址可以包含服务端生成的签名参数。跨域下载不携带 WebDAV 账号密码或 Folio 登录 Cookie；写入和目录操作只允许同源跳转，最多跟随 5 次。完整本地调试服务同样支持连接真实网盘。

## 两端交换资料

- 网页版和本地版填写相同的 WebDAV 地址与账号。在来源端点击「上传」，确认后将当前完整备份写入网盘。
- 在目标端点击「拉取」。自动从 `Folio_Backup` 读取备份并打开预览，不修改当前卡包；目录或备份尚不存在时，会提示先在来源端上传。
- 加密备份需先输入原卡包的加密密码。WebDAV 应用密码和卡包加密密码是两种不同的密码。
- **合并**只添加新的记录 ID，保留当前已有记录，包括同 ID 的当前内容。
- **替换**使当前卡包与拉取的快照一致，包含来源端的修改和删除；当前卡包中独有的记录也会被移除。确认前可先导出备份。
- 导入按目标端现有的加密设置保存。若目标卡包尚未加密，导入加密备份后也会以明文保存；希望始终加密时，先开启目标端卡包加密，再拉取。

## 互不干预

默认未配置连接，所有上传、拉取和导入均由用户手动触发。日常编辑仍只保存到当前端原有的数据位置：网页版的 D1 数据库，或桌面版的本地资料文件。

两端只在手动操作时交换资料，彼此不会自动覆盖。若需要各自独立的网盘备份，可以连接不同 WebDAV 账号或不同根地址。配置弹窗中的「断开」只清除当前端连接，不删除网盘文件或改变卡包。个人显示设置、账户登录信息、WebDAV 配置和密码不随备份交换。

## 文件保护与兼容性

- 最大备份大小为 12 MiB，与已有备份导入限制一致。损坏、错误格式、超限文件不会导入。
- 上传前读取远程版本，覆盖须再次确认。新建使用 `If-None-Match: *`，覆盖使用强 ETag 的 `If-Match`，避免检查后被其他设备修改的文件遭到覆盖。
- 网盘不提供强 ETag 时允许读取，但不覆盖现有文件。服务端需要正确遵守 HTTP 条件写入语义。
- 下载发生跳转时，从原 WebDAV 接口读取文件 ETag，并比较下载前后的版本；对象存储下载地址的 ETag 不用于覆盖 WebDAV 文件。
- 上传后会读回并校验文件内容。若上传期间连接中断或校验失败，远程文件可能已写入，应先拉取检查再决定重试。
- 上传时通过 `MKCOL` 创建内置备份目录，已存在则确认可访问后继续。不会删除远程文件，也不在后台轮询。

## 开发验证

```powershell
node --experimental-strip-types --test tests/webdav.test.ts tests/storage.test.ts
npm run test:webdav-worker
npm run build
npm run desktop:frontend
npm run desktop:test
```

Worker 测试使用临时 D1 与模拟 WebDAV，不读取生产数据库或真实网盘。实现遵循 [Cloudflare Request 重定向行为](https://developers.cloudflare.com/workers/runtime-apis/request/) 和 [reqwest 请求超时与重定向配置](https://docs.rs/reqwest/0.13.5/reqwest/struct.ClientBuilder.html)。实际服务商的认证、路径和条件写入支持，仍需使用该服务的测试账号验收。
