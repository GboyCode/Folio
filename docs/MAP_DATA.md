# 信息地区地图

首页「我的信息」按记录的国家 / 地区汇总银行卡、U 卡、SIM / eSIM 和地址。不同语言的同一地区名称合并统计；保留原始记录。全球、自定义和缺少坐标的记录保留在各自分类页面，不生成虚假的定位点。

地图只表示地区分布，标记使用地区代表坐标，不表示实际住址、设备位置或旅行足迹。附近标记在窄屏合并，点击点位会弹出小卡片，列出组内各地区的记录；点击记录打开详情。弹层支持 Escape、点击外部或关闭按钮收起。旗帜显示策略不改变地区代码或坐标。

总览固定为一屏高度，地图紧接四张概览卡片，等比例适应剩余空间。平铺视图保持简洁，记录通过点位弹层查看；分类页面保持正常滚动。

地图可视框裁去原始 SVG 上下的空海域，保留完整陆地轮廓；在内容宽度和剩余可见高度内取最大等比例尺寸，减少两侧与底部留白。底图、流光和点位共用同一可视框，缩放不会改变坐标对齐。

有记录的地区点位通过完整灰色弧线汇聚至浙江区域（展示锚点约东经 120°、北纬 29°）。连续渐变流光沿起点到汇聚点流动，亮部带平滑拖尾并无缝循环，不使用分段虚线；终点仅显示圆点，不标名称。这只是视觉连线，不代表网络攻击、实时流量或用户位置。窄屏连线跟随合并后的点位，线层不拦截点击。地图右上角可暂停动效，系统减少动态效果时停止 SVG 动画、仅显示静态连线；没有可定位记录时不显示连线和汇聚点。

地图轮廓和坐标随站点一起发布并缓存，展示过程不请求外部地图、定位或地理编码服务。

## 拖动切换地球

- 在平铺地图空白处按住鼠标左键拖动超过 8 像素，原有点阵在约 850ms 内收拢为球体。普通点击点位仍打开地区弹层；右上角「地球视图」提供键盘和触屏入口。
- 地球使用同一陆地轮廓上的 4,778 个点，通过正交投影展示前后深度。拖动时跟随手势转向，松手后缓慢自转；可暂停旋转或切回平铺地图。平铺时原有浙江汇聚流光保持不变。
- 地球右侧显示最靠近正面的地区信息，随手动转向或自动旋转切换，并用切换阈值避免相邻地区反复闪动。点击地球点位或地区标签，可将该地区转到正面并展示记录；点击记录打开原有详情。鼠标移入、移出、悬停或聚焦卡片区均不暂停旋转与切换；拖动松开后继续自转，暂停由右上角按钮控制。无法定位的地区可通过标签查看，不生成虚假点位。
- 窄屏卡片位于地球下方，低矮屏幕改为并排布局。卡片区独立滚动，总览不超过当前可见高度。
- 系统减少动态效果时直接切换形态并停止自转；页面隐藏时停止绘制，离开总览时清理动画与事件监听。动画使用 Canvas 2D，不新增图形运行库或外部服务。

点阵生成：`node scripts/build-world-dots.mjs`，从已缓存的 `public/world-map.svg` 采样到 `src/world-dots.json`。更新海岸线后需重新生成点阵，普通构建直接使用本地点阵。

## 数据来源

- 陆地轮廓：[Natural Earth 110m land](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)，[公有领域使用条款](https://www.naturalearthdata.com/about/terms-of-use/)。仅取海岸线，采用等距圆柱投影并移除南极大陆用于概览排版。
- 地区代表坐标：[Google DSPL canonical countries.csv](https://github.com/google/dspl/blob/master/samples/google/canonical/countries.csv)。提取 244 个有效地区坐标，保留项目 BSD 许可全文于 `public/map-data-license.txt`，随站点发布。
- 地区中文名称与别名：沿用 `src/countries.ts` 的地区解析与浏览器 `Intl.DisplayNames`。

生成脚本：`node scripts/build-world-map.mjs`。输出 `public/world-map.svg`、`src/region-coordinates.ts`；普通构建使用已生成文件，无需重新下载。更新上游数据时应重新核对坐标与许可。

## 导航

- 「我的信息」是总览，显示全部类型数量和全球分布；从地图点位弹层进入记录详情。
- 银行卡和 U 卡合并到「支付信息」，页内通过「全部 / 银行卡 / U 卡」切换；首页的两个概览入口分别打开对应分类，新增与空状态的图鉴入口沿用当前分类。
- SIM / eSIM 和「地址信息」各有独立页面；地址入口统一使用定位图标。
- 手机底栏保留信息、支付信息、SIM 和地址信息；收藏、图鉴和设置可从左上角导航抽屉访问。
