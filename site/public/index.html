GOOD TO KNOW

开始之前，
你可能想知道。

我的信息会上传到 Folio 吗？+

Windows 版将资料保存在你选择的本地文件夹。自部署网页版将资料写入你自己的 Cloudflare D1。这个产品官网不提供账号服务，也不保存你的卡包。

所有数据默认加密吗？+

加密需要在「数据隐私」中主动开启。开启后，卡包使用 AES-256-GCM 在当前设备加密；加密密码不上传。显示名称、头像和应用偏好不属于加密卡包。忘记加密密码无法恢复资料，请妥善保管密码和备份。

离线版需要安装很大的运行环境吗？+

使用安装包不需要 Node.js、Rust 或 Visual Studio。客户端使用系统 WebView2；若系统尚未安装，安装器会联网补充该运行时。安装完成后，日常资料管理可以离线使用。

可以修改源码或自己部署吗？+

可以。Folio 原创代码采用 MIT 协议，使用和分发时请保留 RyanLin 的版权及许可声明。第三方卡面、商标和其他素材保留原权利人的权利，详见仓库中的第三方许可说明。

如何备份或升级？+

在应用中导出 JSON 备份，导入时可以预览后选择合并或替换。普通备份可能包含明文资料，请妥善保存。当前版本请从 GitHub Releases 手动下载升级，自动更新尚未启用。
